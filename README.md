# JavaScript-Kurse

Exercices pratiques JavaScript suivant la progression du cours basé principalement sur javascript.info.

Chaque chapitre contient des exercices à compléter, des quiz de prédiction et les corrigés des exercices comportementaux.

## Chapitres

- `ch01-hello-world` — environnement d'exécution, `<script>`, markup moderne, scripts externes, `src`, chemins et organisation inline/externe.
