# Kapitel 2 — JavaScript Fundamentals

Diese Übungen (= exercices) trainieren die Inhalte aus **Kapitel 2: JavaScript Fundamentals**.
Schwierige deutsche Wörter und Ausdrücke werden im Kommentar direkt auf Französisch erklärt.

## Arbeitsmethode (= méthode de travail)

**VERSTEHEN → VON HAND DENKEN → VORHERSAGEN → CODE SCHREIBEN → AUSFÜHREN → BEOBACHTEN → ERKLÄREN**

Es gibt hier **keine Quiz-Dateien**. Jede Aufgabe verlangt echten Code: schreiben, ergänzen, reparieren, testen oder mehrere bekannte Regeln kombinieren.

## Ausführung

Node.js wurde für die Lösungen mit **Node.js v22.16.0** geprüft.

```bash
node exercises/exercise01-benutzerdaten.mjs
node solutions/solution01-benutzerdaten.mjs
```

`exercise04-browser-interaktion.html` ist eine Browser-Aufgabe, weil `alert`, `prompt` und `confirm` Browser-APIs sind. Diese Datei wird im Browser geöffnet und nicht mit Node.js ausgeführt.

## Übungen

01. Benutzerdaten richtig speichern — `let`, `const`, Zuweisung, Kopie
02. Datentypen untersuchen — `typeof`, `null`, `undefined`, primitive Typen
03. Formulardaten umwandeln — explizite Typkonvertierung und `NaN`
04. Browser-Interaktion — `alert`, `prompt`, `confirm`
05. Rechnung berechnen — Operatoren, Priorität, zusammengesetzte Zuweisung
06. Zugang vergleichen — Vergleiche, `==` vs `===`
07. Entscheidungskette — `if`, `else if`, `else`, `?:`
08. Login-Regeln — `&&`, `||`, `!`, Short-Circuit
09. Standardwerte — `??` vs `||`
10. Anmeldeversuche — `while`, `do...while`
11. Schleifen steuern — `for`, `break`, `continue`, Labels
12. Support-Ticket — `switch`, `case`, `default`, Fall-through
13. Preisberechnung zerlegen — Function Declaration, Parameter, Argumente, `return`, Scope
14. Robuste Funktionen — Default-Parameter, mehrere Rückgabewege, Shadowing
15. Funktion als Wert — Function Expression, speichern, kopieren, später aufrufen
16. Callback praktisch einsetzen — Callback und anonyme Funktion
17. Funktionsformen gezielt einsetzen — Declaration vs Expression, Erzeugungszeit, Block-Scope
18. Arrow Functions — Parameter und implizite Rückgabe
19. Arrow-Fehler reparieren — Block, `return`, Objekt-Rückgabe
20. JavaScript-Fallen reparieren — Konvertierung, `typeof null`, `||`/`??`, `==`/`===`
21. Kaputtes Mini-Programm retten — Syntax-, Referenz-, Typ- und Logikfehler unterscheiden
22. Abschlussprojekt — Bestellsystem ohne zukünftige Konzepte wie Arrays oder Objekte
